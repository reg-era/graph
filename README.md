# graph

## Type of quering 
```
    Simple Query (Basic retrieval)
    Query with Variables (Dynamic input)
    Query by Condition (Filtering)
    Query with Pagination (Limit and offset or cursor-based pagination)
    Query with Sorting (Order results by fields)
    Query with Nested Relationships (Similar to SQL joins)
    Query with Aliases (Renaming results to avoid conflicts)
    Query with Fragments (Reusable pieces of queries)
```
